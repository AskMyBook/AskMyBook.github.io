# مساعد المذاكرة (HTML + CSS + JavaScript)

هذا الفولدر بالكامل هو الموقع. لازم يترفع على **جذر** المستودع أو فرع `gh-pages`، مش جوّه فولدر فرعي زي `j/`.

## تشغيل محلي / نشر
1. **مفيش كتب على الموقع.** ارفع **كل** محتويات الفولدر ده (بما فيها `.nojekyll`) لجذر المستودع من غير أي PDF.
2. Settings → Pages → Source: Deploy from branch → اختر الفرع والمجلد `/ (root)`.
3. كل مستخدم يفتح الموقع ويضغط ➕ «إضافة كتب» ويختار ملفات الـ PDF بتاعته (كذا كتاب مع بعض). الكتب بتتحفظ في متصفحه (IndexedDB) مرة واحدة، وكل ما يفتح الموقع يلاقيها، والذكي بيفهرسها ويعرف اللي فيها.
4. الكتب على جهاز كل شخص بس (مش مشتركة بين الناس ولا بين الأجهزة) ومبتترفعش على أي سيرفر. في Safari على الآيفون ضيف الموقع للشاشة الرئيسية عشان المتصفح ميمسحش البيانات لو مفتحتوش أسبوع، ومتستخدمش وضع التصفح الخاص.

⚠️ ملف `.nojekyll` مهم: من غيره GitHub Pages بيشغّل Jekyll، ولو مفيش `index.html` في الجذر بيعرض الـ README بدل الموقع الحقيقي — وده اللي كان بيحصل.

## ✅ قايمة التجهيز للإنتاج (Production checklist) — آخر تحديث
**اختبار كل حاجة بأمر واحد:** `npm install && pip install -r requirements-dev.txt && npm run test:all`
التقرير في الآخر بيطبع كل مجموعة **PASSED / FAILED / SKIPPED** — والـ SKIPPED معناه «ماتحققناش منه»، مش نجاح. وأي FAILED بيخلي الأمر يخرج بـ 1 (والـ CI بيفشل).

| المجموعة | الأمر | بتختبر إيه |
|---|---|---|
| lint | `npm run lint` | ESLint على كل الكود |
| server | `npm test` | API، الصوت، الـ auth، الحدود (quota)، request id، السجلات من غير أسرار |
| browser | `npm run test:browser` | E2E في Chromium حقيقي: رفع/فتح/مسح كتب، مشغّل الصوت، الأخطاء |
| conversation | `npm run test:conversation` | المدرّس + مقاطعة الصوت |
| study | `npm run test:study` | امتحانات، تصحيح، نقاط ضعف، ملاحظات، خطة، بحث، تعليقات |
| cloud | `npm run test:cloud` | حسابات، مزامنة، تعارض offline، عزل المستخدمين، نسيت الباسورد، مسح البيانات/الحساب |
| rls | `npm run test:rls` | **Postgres + pgvector حقيقي**: قواعد RLS في `server/supabase.sql` (مستخدم مايشوفش بيانات غيره) |
| quality | `npm run test:quality` | الاستشهادات (مفيش استشهاد مخترع)، JSON مُتحقق منه + إعادة المحاولة، سياق «اشرحها تاني» |
| scale | `npm run test:scale` | PDF ‏600 صفحة، OCR حقيقي (Tesseract) لكتاب صور، PDF بايظ، موبايل/تابلت/لابتوب، إتاحة |
| regress | `npm run test:regress` | بيدوس على **كل** زرار وإعداد في الموقع (كمبيوتر + موبايل) ومايقبلش أي خطأ JS / Unhandled Rejection، + الذكاء المحلي، مهلة الذكاء، حد حجم الـ PDF |
| live | `npm run test:live` | محركات الصوت الحقيقية — **SKIPPED من غير مفاتيح** |

قبل النشر:
1. `npm run bundle` بعد أي تعديل في `server/` (الـ CI بيتأكد إن `worker-bundle.js` متحدّث).
2. على السيرفر: `ALLOWED_ORIGINS` = رابط موقعك بالظبط.
3. لو فيه حسابات: شغّل `server/supabase.sql` في Supabase ← SQL Editor، وحط `SUPABASE_URL` و`SUPABASE_ANON_KEY` في `config.js` **وفي** السيرفر، و`REQUIRE_AUTH=true`، و`SUPABASE_SERVICE_ROLE_KEY` **على السيرفر بس** (لمسح الحساب).
4. ظبط `QUOTA_*` حسب ميزانيتك (القيم الافتراضية في `server/.env.example`).
5. في Supabase ← Authentication: فعّل «Confirm email»، وحط رابط موقعك في Redirect URLs (عشان رابط نسيت الباسورد).
6. `config.js` فيه بس قيم عامة (رابط السيرفر، anon key). **مفيش أي مفتاح سيرفر في الموقع** — `npm test` بيتأكد.

متغيرات جديدة: `SUPABASE_SERVICE_ROLE_KEY` (سيرفر بس)، `QUOTA_CHAT_PER_DAY`، `QUOTA_IMAGES_PER_DAY`، `QUOTA_TTS_CHARS_PER_DAY`، `QUOTA_STT_BYTES_PER_DAY`، `QUOTA_EMBED_TEXTS_PER_DAY`، `COST_PER_1K_OUTPUT_CHARS`، `LOG=off`. وفي `config.js`: `maxPdfMB` (الافتراضي 300).

حدود معروفة: الحدود اليومية في ذاكرة كل نسخة سيرفر (بتتصفّر لو السيرفر اتعمله restart، ومش مشتركة بين نسخ Cloudflare الكتير — للدقة الكاملة محتاجة KV/Durable Object). المحادثات محفوظة على الجهاز بس (مش بتتزامن). جودة إجابات الذكاء الحقيقي ماتقاستش أوتوماتيك (الاختبارات بتستخدم ردود ثابتة عشان تختبر الكود حوالين الذكاء).

## الصوت التلقائي + إعدادات للطلبة (آخر تحديث)
- **ترتيب الصوت «تلقائي»:** سيرفر الموقع (لو صاحب الموقع ظبطه، زي «شاكر» من Azure) ← **Puter / ElevenLabs لو الطالب سجّل دخول Puter** (مجاني ومن غير فيزا، وبيطلع من رصيده هو مش من رصيدك) ← صوت المتصفح ← «كريم» اللي بيشتغل جوه الجهاز. أي طالب يقدر يثبّت محرك من ⚙️ ← الصوت.
- **العربي عمره ما بيتقري بصوت إنجليزي:** لو المتصفح مفيهوش صوت عربي، المشغّل بيكمّل بالمحرك اللي بعده وبيقول السبب.
- الطالب اللي مش مسجّل في Puter بيشوف زرار واضح في ⚙️ ← الصوت: «🎙️ صوت أوضح وأطبع (ElevenLabs) — سجّل دخول Puter مجانًا»، وبتظهر له نصيحة مرة واحدة.
- **الإعدادات للناس مبسّطة:** مفاتيح API (Gemini/Claude)، الذكاء المحلي، البحث بالمعنى، تفاصيل الصوت (صوت واحد/اللغة/الطبقة/سطور الحالة)، ورسالة «لصاحب الموقع…» كلهم مخفيين. كلهم لسه موجودين في الكود ولسه بيشتغلوا: **صاحب الموقع يظهّرهم** بـ `devSettings: true` في `config.js`، أو بفتح الموقع بـ `?dev=1` (بيتفتكر في المتصفح ده) و`?dev=0` يقفله.

## إصلاحات المراجعة الشاملة
- **الذكاء المحلي رجع شغال:** اختيار «💻 محلي على جهازك» في ⚙️ ← المزوّد. ملف `localai.js` بيتحمّل بس لما تختاره (مش مع فتح الموقع)، والموديل مبيتحمّلش غير لما تسأل أو تدوس «حمّل الآن». محتاج متصفح بيدعم WebGPU (Chrome/Edge حديث) — ولو مش مدعوم بتظهر رسالة واضحة.
- **حجم الكتاب (حدّين واضحين):** `maxPdfMB` في `config.js` (300 ميجا) = أكبر كتاب يتحفظ على الجهاز. `syncMaxPdfMB` (50 ميجا) = أكبر كتاب يتزامن مع الحساب، ولازم يساوي `file_size_limit` في `server/supabase.sql` (وده حد Supabase المجاني). الكتاب الأكبر من 50 بيتحفظ على الجهاز بس ومعاه رسالة إنه مش هيتزامن (بدل ما يتقفل).
- **المزامنة:** الإعدادات بتتزامن (من غير مفاتيح API)، والكتاب اللي بيتمسح على جهاز بيتمسح من التاني ومايرجعش، والمسح وإنت أوفلاين مابيضيعش مع تحديث الصفحة، وتسجيل حساب تاني على نفس الجهاز بيسأل قبل ما يرفع بيانات الحساب الأول، و«امسح بياناتي من السحابة» بيخرجك من الحساب عشان مايترفعش كل حاجة تاني.
- **مهلة الذكاء:** Claude/Gemini المباشر 60 ثانية لحد أول رد (`aiTimeoutMs` في `config.js`)، وPuter 90 ثانية — بدل «بيفكر» للأبد.

## ملاحظات مهمة (بعد التحديث)
- مكتبة عرض الـ PDF بقت محلية في فولدر `lib/` (لازم يترفع مع الموقع).
- ملفات الـ PDF **مش هتفتح** لو فتحت `index.html` بالضغط المزدوج (file://) — المتصفح بيمنع ده. شغّل سيرفر محلي: `python -m http.server` وافتح `http://localhost:8000`، أو استخدم GitHub Pages.
- أسماء الملفات حرة: اسم الكتاب في القايمة بيتاخد من اسم الملف، وإضافة ملف بنفس الاسم بتستبدل القديم.

## منصة المذاكرة الكاملة — آخر تحديث
كل الحاجات دي شغالة فعلًا وليها اختبارات، ومفيش زرار شكلي.

- **مركز المذاكرة** (زرار المربعات فوق): المكتبة، والملاحظات، والامتحان، ونقط الضعف، وخطة المذاكرة، والبحث.
- **المكتبة:**
  - كارت لكل كتاب فيه صورة أول صفحة، وتاريخ الإضافة، ونسبة القراءة (من الصفحات اللي اتفتحت فعلًا)، وآخر صفحة.
  - أزرار: كمّل، ذاكر مع الـ AI، غيّر الاسم، نزّل، امسح.
- **القارئ** (زرار ⋮):
  - دوّر في الكتاب، ملء العرض، الصفحة كاملة، ملء الشاشة.
  - تنزيل الـ PDF الأصلي، وتنزيل الـ PDF **بالكتابة** (عن طريق pdf-lib في `lib/`).
  - معلومات الملف، و«صحّحلي اللي كتبته بخط إيدي».
  - «📋 انسخ النص» فوق أي جزء بتحدده.
- **الرسم:**
  - قلم، ورصاص، وهايلايتر بشفافية تتظبط، ونص، وممحاة.
  - أشكال: خط، سهم، مستطيل، دايرة.
  - «تحديد وتحريك»: تحرّك أي كتابة أو شكل، أو تكبّره من المربع الأزرق، أو تمسحه.
  - تراجع وإعادة (Ctrl+Z / Ctrl+Y)، وكل حاجة بتتحفظ على صفحتها.
- **الامتحان:**
  - بتختار الكتاب، والفصول أو الدروس، وعدد الأسئلة، والصعوبة (سهل / متوسط / صعب / صعب جدًا).
  - الأنواع: اختيار، صح وغلط، أكمل، قصير، مقالي، مسائل. ووقت اختياري بيسلّم لوحده لما يخلص.
  - التقرير فيه:
    - النسبة، وكل سؤال صح ولا غلط، والشرح.
    - الدرس والصفحة لكل سؤال، والمواضيع اللي محتاج تراجعها، وزرار «اتدرّب عليها».
- **نقط الضعف:**
  - محسوبة من إجاباتك الحقيقية بس، سواء في الامتحانات أو أسئلة الشات أو «اختبرني».
  - «بتغلط كتير في …» بيظهر لما تغلط مرتين أو أكتر في نفس الموضوع وصحتك فيه أقل من 60%.
- **خطة المذاكرة:**
  - محسوبة من فهرس الكتاب، والصفحات اللي قريتها، ونقط ضعفك، وميعاد الامتحان أو عدد الأيام.
  - فيها مهام بتعلّم عليها، و«حدّث الخطة حسب تقدّمي».
- **الملاحظات:** ملاحظة شخصية أو مربوطة بصفحة ودرس، أو «📝 احفظ كملاحظة» تحت أي رد. وفيها تعديل ومسح وبحث.
- **البحث:** في الكتاب المفتوح أو في كل كتبك، بالصفحة والدرس ومقتطف من النص، وبتدوس على النتيجة تروح للصفحة.
- **صورة سؤال:** زرار 📎، أو تلصق الصورة، أو تسحبها على الشات.
  - مع مزوّد بيشوف الصور (Claude أو Gemini أو Puter أو سيرفر فيه vision)، الصورة بتتبعت للموديل.
  - مع المجاني، الصورة بتتقري بالـ OCR، والمدرّس بيقول ده، وخط الإيد ممكن ميتقراش.
- **لغة الواجهة:** زرار EN / ع فوق. ردود المدرّس بتمشي مع لغتك تلقائيًا.

### الحسابات (اختياري، Supabase)
- **من غير إعداد:** كل حاجة على الجهاز بس، ومفيش زرار دخول وهمي.
- **للتفعيل:**
  1. اعمل مشروع مجاني على supabase.com.
  2. شغّل `server/supabase.sql` في SQL Editor. ده بيعمل الجدول وقواعد RLS وbucket خاص اسمه `books`.
  3. حط `supabaseUrl` و`supabaseAnonKey` في `config.js`، أو `SUPABASE_URL` و`SUPABASE_ANON_KEY` على السيرفر.
- **المفتاح العام (anon) آمن** يتحط في الموقع، لأن الحماية في قاعدة البيانات نفسها: كل مستخدم بيشوف صفوفه وفولدر كتبه هو بس. **متحطش service_role key في الموقع أبدًا.**
- **اللي بيتزامن:** الكتب (PDF لحد 50 ميجا)، والكتابة عليها، والملاحظات، والتقدّم، ونقط الضعف، والخطط، والامتحانات. الأحدث بيكسب لكل بيانة، والمكتبة بتتدمج فمفيش كتاب بيضيع.
- **`REQUIRE_AUTH=true` على السيرفر:** أي طلب للذكاء أو الصوت لازم يكون من مستخدم مسجّل دخول، والتوكن بيتأكد منه عند Supabase، والحد بيتحسب لكل مستخدم.

### الاختبارات الجديدة
- `npm run test:study`: المكتبة، والقارئ، والرسم، والتنزيل بالكتابة، والصور، وخط الإيد، والملاحظات، والامتحان، والوقت، ونقط الضعف، والخطة، والبحث. الموديل فيه متقلّد.
- `npm run test:cloud`: جهازين بنفس الحساب، وحساب تاني ممنوع يشوف أو يعدّل حاجة، و`REQUIRE_AUTH`. Supabase فيه متقلّد بنفس قواعد RLS.
- **لسه محتاج تجربة حقيقية:** Supabase الحقيقي (شغّل `supabase.sql` في مشروعك)، وجودة الامتحانات مع موديل حقيقي، والـ OCR لخط الإيد.

## «كريم» بقى بيقرا عربي مفهوم (تشكيل تلقائي) — آخر تحديث
- **سبب المشكلة:** «كريم» (Piper) متدرّب على كلام عربي **متشكّل**، والموقع كان بيبعتله كلام من غير تشكيل، فالنطق كان بيطلع مش مفهوم.
- **الحل:** قبل ما «كريم» يقرا، الكلام العربي بيتشكّل تلقائيًا جوه متصفح الطالب:
  - بموديل **CATT** (رخصته Apache 2.0)، نسخة int8 حجمها حوالي 21 ميجا في فولدر `models/`، **ولازم الفولدر ده يترفع مع الموقع**.
  - بيتحمّل مرة واحدة ويتخزّن، وبعدها بيشكّل الجملة في أقل من ثانية.
  - الإنجليزي والأرقام والرموز بيفضلوا زي ما هما.
- ده نفس اللي Piper على السيرفر بيعمله (libtashkeel). من غير تسجيل ولا مفتاح ولا فيزا ولا لابتوب.

## الصوت الطبيعي المجاني (Puter — OpenAI) — آخر تحديث
- **صوت ElevenLabs الطبيعي (`eleven_multilingual_v2`)** بقى محرك الصوت الأساسي بعد سيرفر الموقع، من غير مفتاح ولا فيزا ولا سيرفر. عربيه واضح وإنجليزيه طبيعي بنفس الصوت. أصوات OpenAI (`gpt-4o-mini-tts`) موجودة كاختيار، وإنجليزيها ممتاز بس عربيها أضعف.
- **الطالب بيسجّل دخول Puter مرة واحدة بس** من ⚙️ ← الصوت ← «سجّل دخول Puter». Puter شغال بنظام «المستخدم بيدفع»: كل طالب بيستهلك من رصيده المجاني هو، وصاحب الموقع مبيدفعش حاجة.
- **صوت واحد للعربي والإنجليزي**، وبتعليمات إنه يتكلم مصري طبيعي والإنجليزي طبيعي. تقدر تختار الصوت: Adam (الافتراضي) أو George أو Brian أو Daniel أو Sarah أو Matilda، أو أصوات OpenAI.
- **لو الطالب مش متسجّل، أو رصيده خلص، أو Puter واقع:** الصوت بيكمّل لوحده بـ«كريم»، ويظهر تنبيه مرة واحدة. ولو الرصيد خلص، Puter بيقف ١٠ دقايق ويتجرّب تاني.
- **الاختبار:** `npm run test:puter`. مكتبة Puter فيه متقلّدة، فجودة صوت OpenAI الحقيقية ورصيد Puter الحقيقي محتاجين تجربة بنفسك.

## ذكاء المدرّس + صوت واحد (آخر تحديث)
- **فهم المتابعة:** «مش فاهم»، «طب هات مثال»، «طب لو الكتلة زادت؟»، «Can you explain that in English?»، «رجعها بالعربي»، «مش فاهم الـ acceleration» كلها بتتفهم كتكملة لنفس الموضوع.
- **ذاكرة صغيرة بدل المحادثة كلها:** بيتبعت للموديل «حالة المحادثة» فيها:
  - الموضوع وآخر سؤال والمكان في الكتاب.
  - سؤال المدرّس اللي مستني إجابة، ومستوى فهم الطالب.
  - آخر ٢–٣ أدوار بس من المحادثة.
- **سؤال عربي والكتاب إنجليزي (أو العكس):** الموديل السريع بيطلّع كلمات بحث بلغة الكتاب، مرة واحدة لكل موضوع.
- **الرد على قد السؤال:**
  - من غير قالب ثابت، ومن غير «بالتأكيد/طبعًا»، ومن غير إيموجي في الكلام.
  - السؤال في آخر الرد بس لما يفيد.
  - «الإجابة فقط» بيدّي الإجابة بس.
  - «الإجابة دي صح؟» بيصحّح إجابة الطالب.
  - المسائل بتتحل بالترتيب: المطلوب ← المعطيات ← القانون ← التعويض ← الناتج.
- **صوت واحد (الافتراضي):**
  - نفس الصوت بيقرا العربي والإنجليزي والمخلوط، ومفيش تبديل صوت حسب اللغة.
  - الإعدادات كلها في مكان واحد: `VOICE_PROVIDER` / `VOICE_ID` / `VOICE_MODEL` / `VOICE_SPEED` / `VOICE_STABILITY` / `VOICE_SIMILARITY` / `VOICE_STYLE`. الشرح في `server/voice-config.js` و`server/.env.example`.
  - تقدر ترجع للطريقة القديمة (صوت عربي + صوت إنجليزي) من ⚙️ ← «صوت المدرّس»، أو على السيرفر بـ `VOICE_ONE=false`.
- **المقاطعة في المحادثة الصوتية:**
  - «استنى» بتوقّف الصوت على طول.
  - «كمّل» بتكمّل من نفس المكان.
  - أي سؤال تاني بيوقف الشرح القديم ويتبعت بسياق المحادثة.
  - ونفس الكلام شغال لو كتبته.
- اختبار المحادثة كاملة: `npm run test:conversation`. الموديل والمايك والصوت فيه **متقلّدين**، فبيختبر الفهم والسياق والمقاطعة، مش جودة موديل حقيقي.

## نظام الصوت (TTS) — ده المرجع الحالي
> الأقسام القديمة تحت اللي بتتكلم عن صوت Gemini أو Gemini Live أو Puter **مبقتش مستخدمة**. الصوت دلوقتي طبقة مستقلة ومفيهاش Gemini خالص.

- **فصل كامل:** المدرّس الذكي بيولّد النص بس، وطبقة `tts.js` بتحوّله لصوت بس. ولو الشات شغال بـ Gemini، الصوت برضه مبيستخدمش Gemini.
- **المحركات بالترتيب:**
  1. سيرفر الموقع `POST /api/tts`: Piper على سيرفرك، أو أي سيرفر TTS خاص، أو Azure / ElevenLabs / OpenAI. المفاتيح على السيرفر بس.
  2. «كريم» (Piper) جوه المتصفح: مفتوح المصدر، من غير مفتاح ولا حدود. أول مرة بيحمّل حوالي 60 ميجا.
  3. صوت المتصفح: **احتياطي بس**.
- **الصوت مبيبدأش لوحده:** بيشتغل بس لما الطالب يدوس «اسمع» تحت الشرح، أو يشغّل القراءة التلقائية أو المحادثة الصوتية بنفسه. وبيتقري النص ده بس.
- **المشغّل:** تشغيل، إيقاف مؤقت، كمّل، إيقاف، إعادة، وسرعة 0.75× / 1× / 1.25× / 1.5×. فيه مؤشر «بيولّد الصوت…» ونسبة التحميل أول مرة.
- **بيولّد على دفعات:** الجملة الأولى بتتولّد وتشتغل على طول، والباقي بيتجهّز في الخلفية.
- **لو محرك فشل:** الصوت بيكمّل من نفس الجملة بالمحرك اللي بعده، مع رسالة صغيرة. الصفحة عمرها ما بتقع.
- **الإعدادات (⚙️):** محرك الصوت، المدرّس (عربي / English)، الصوت، اللغة، السرعة، وطبقة الصوت لو المحرك بيدعمها. كلها بتتحفظ في المتصفح.
- **تشغيله محليًا وعلى سيرفر، وإضافة محرك جديد أو صوتك المستنسخ:** الشرح بالتفصيل في `server/README.md`، قسم «Text-to-speech». وبعد ما تشغّل السيرفر اتأكد إن كله شغال بـ `bash server/smoke-tts.sh http://localhost:8787`.
- **أحسن نطق عربي:** شغّل Piper على السيرفر. نسخة السيرفر بتشكّل الكلام العربي تلقائيًا (tashkeel) قبل ما تقراه، فنطقها أحسن من نسخة المتصفح.

## الاختبارات
- `npm test`: السيرفر وطبقة الصوت. Node بس، ومن غير مفاتيح ولا مكتبات. بيغطي:
  - صحة كتابة كل ملفات JS، وتشغيل السيرفر و`/v1/health`.
  - إعداد `TTS_PROVIDER` و`TTS_AUTO_FALLBACK`، واسم محرك غلط، ومفتاح ناقص.
  - التحقق من الطلبات، والـ CORS.
  - السرعة لكل محرك، والمفتاح الغلط (401)، وحد الطلبات (429)، ومحرك بيعلّق (timeout)، والانتقال لمحرك تاني.
  - إن `worker-bundle.js` متطابق مع المصدر، وإن مفيش مفاتيح في الملفات العامة.
- `npm run test:browser`: الموقع في Chrome حقيقي. محتاج مرة واحدة: `npm i -D playwright && npx playwright install chromium`. بيغطي:
  - تشغيل الموقع من غير سيرفر.
  - رفع كذا كتاب، وPDF مزيّف، وPDF بكلمة سر، والحفظ بعد التحديث، والمسح.
  - السيرفر واقف وقت الفتح وبعدين بيرجع، أو بيقع في النص.
  - كل السرعات، وتغيير السرعة وقت التشغيل.
  - إيقاف مؤقت / كمّل / إيقاف / إعادة، والإلغاء وقت التوليد، ورد جديد بيوقف القديم.
  - تحرير الذاكرة، وفشل الصوت، وصوت المتصفح.
- بعد أي تعديل في `server/tts.js` أو `server/worker.js` شغّل `npm run bundle` عشان `server/worker-bundle.js` يتحدّث. `npm test` بيقولك لو نسيت.
- **`npm test` و`npm run test:browser` بيستخدموا نسخ تجريبية (mock) من المحركات.** بيثبتوا إن كود الموقع والسيرفر بيتعامل صح (السرعة، الأخطاء، الاحتياطي، الأصوات). **مش** بيثبتوا إن Azure أو غيره بيرد فعلًا.
- `npm run test:live`: **اختبار حقيقي من غير mock.** بيكلّم المحركات الحقيقية بمفاتيحك، اللي بيقراها من الـ env أو `server/.env`.
  - بيجرّب لكل محرك متظبط: فصحى، ومصري، وEnglish، ومختلط، ومعادلة، وإن السرعة بتتطبّق فعلًا.
  - بيحفظ الصوت في `tests/output/` عشان تسمعه بودنك.
  - من غير مفاتيح بيكتب SKIPPED.
- **لسه محتاج تجربة بمفاتيح حقيقية:** صوت Azure/ElevenLabs/OpenAI/Piper الفعلي (`npm run test:live`)، وخدمات الذكاء المجانية، ونطق «كريم» العربي (الموديل بيتحمّل من Hugging Face).

## متغيرات السيرفر (Environment variables)
| المتغير | لازم؟ | الوظيفة |
|---|---|---|
| `ALLOWED_ORIGINS` | أيوه | رابط موقعك، زي `https://اسمك.github.io`. أي موقع تاني بياخد 403 |
| `AZURE_SPEECH_KEY` + `AZURE_SPEECH_REGION` | للصوت الطبيعي | «شاكر» المصري (بيقرا العربي والإنجليزي بنفس الصوت). الـ Region لازم يطابق المفتاح |
| `VOICE_PROVIDER` / `VOICE_ID` / `VOICE_MODEL` / `VOICE_SPEED` / `VOICE_STABILITY` / `VOICE_SIMILARITY` / `VOICE_STYLE` / `VOICE_ONE` | لأ | إعدادات صوت المدرّس في مكان واحد (صوت واحد لكل اللغات) |
| `TTS_PROVIDER` / `TTS_AUTO_FALLBACK` / `TTS_TIMEOUT_MS` | لأ | ترتيب محركات الصوت / الاحتياطي / الحد الزمني |
| `PIPER_URL` أو `TTS_OAI_URL` | لأ | محرك صوت مفتوح المصدر على سيرفرك |
| `ELEVENLABS_API_KEY` / `OPENAI_API_KEY` | لأ | محركات صوت تانية. ولو `OPENAI_API_KEY` للشات بس، حط `OPENAI_TTS_DISABLED=true` |
| `ANTHROPIC_API_KEY` أو `GEMINI_API_KEY` أو `OPENAI_API_KEY` | لأ | ذكاء أقوى للشات. من غيرهم الموقع بيستخدم الذكاء المجاني |
| `RATE_LIMIT_MULTIPLIER`, `MAX_TTS_CHARS` | لأ | حدود الطلبات |

أي إعداد غلط، زي اسم محرك مش معروف أو مفتاح ناقص أو JSON غلط، بيظهر كتحذير في `/v1/health`، وفي ⚙️ ← الصوت في الموقع.

## مراجعة شاملة (تجهيز للاستخدام الحقيقي)
**اتصلّح:**
- رفع ملف اسمه `.pdf` بس مش PDF حقيقي كان بيتحفظ. دلوقتي بيترفض برسالة واضحة.
- كتاب محفوظ وتالف أو محمي بكلمة سر كان بيظهر «مش موجود». دلوقتي بيظهر السبب الحقيقي، مع زرار «ضيف نسخة تانية» وزرار «امسحه».
- المحادثة كانت بتضيع مع أي تحديث للصفحة. دلوقتي بتتحفظ في المتصفح (آخر ٦٠ رسالة + ذاكرة المدرّس)، وفيه زرار «محادثة جديدة».
- الشات كان بيتحوّل للسيرفر حتى لو السيرفر متظبط للصوت بس، فكان بيقف.
- أخطاء الذكاء كانت بتظهر خام (Failed to fetch). دلوقتي رسالة مفهومة حسب السبب (مفيش نت / الخدمة واقفة / حد الطلبات) + زرار «جرّب تاني».
- زرار الميكروفون كان بيختفي من غير سبب في المتصفحات اللي مش بتدعم الكتابة بالصوت. دلوقتي بيفضل ظاهر، ولما تدوسه بيقول السبب والحل.
- آخر خط أو ملاحظة ممكن كانت تضيع لو الصفحة اتقفلت على طول. دلوقتي الحفظ بيحصل فورًا لما الصفحة تستخبى أو تتقفل.
- كود قديم مش مستخدم (رسائل خطأ لكتب كانت على GitHub) اتشال.

**اتضاف:**
- تعديل أي ملاحظة: بأداة النص، دوس على الملاحظة.
- زرار «📝» بيوديك للصفحة اللي بعدها فيها كتابة أو تظليل، وعليه عدد الصفحات دي.
- طلب من المتصفح إنه ميمسحش الكتب لوحده (`storage.persist`) أول ما يبقى فيه كتب.

**حدود لازم تعرفها:**
- الكتب والتظليل والمحادثة محفوظين في المتصفح اللي استخدمته بس. مفيش مزامنة بين الأجهزة.
- لو مسحت بيانات المتصفح بتتمسح. على الآيفون ضيف الموقع للشاشة الرئيسية ومتستخدمش التصفح الخاص.

## صوت «شاكر» المصري (Azure) — خطوات التشغيل
الصوت بيجي من Azure عن طريق سيرفر صغير ببلاش على Cloudflare. المفتاح بيفضل على السيرفر ومبيظهرش في الموقع أبدًا.
- **الباقة المجانية:** نص مليون حرف في الشهر، يعني أكتر من ١٥٠ شرح درس كامل.
- **حد الطلبات:** ٢٠ طلب في الدقيقة. الموقع بيبعت الدرس كله في حوالي ٥ طلبات، ولو الحد اتعدّى بيستنى ثواني ويكمّل بنفس الصوت.

**١) مفتاح Azure (مرة واحدة):**
- ادخل portal.azure.com واعمل حساب. ممكن يطلب كارت للتأكيد بس، والباقة المجانية مش بتتحاسب.
- Create a resource ← ابحث عن **Speech** ← Create.
- اختار Region، مثلًا West Europe، و**Pricing tier: Free F0** ← Review + create ← Create.
- بعد ما يخلص: افتح الـ resource ← **Keys and Endpoint** ← انسخ **KEY 1** و**Location/Region**، زي `westeurope`.

**٢) السيرفر على Cloudflare (مرة واحدة، ببلاش):**
- ادخل dash.cloudflare.com ← **Workers & Pages** ← Create ← Worker ← Start with "Hello World" ← سمّيه `study-tutor` ← Deploy.
- **Edit code** ← امسح كل اللي فيه، والصق محتوى الملف `server/worker-bundle.js` كله ← Deploy.
- Settings ← **Variables and Secrets** ← ضيف:
  - `AZURE_SPEECH_KEY` = KEY 1، ونوعه **Secret**.
  - `AZURE_SPEECH_REGION` = الـ region، زي `westeurope`.
  - `TTS_PROVIDER` = `azure`
  - `ALLOWED_ORIGINS` = رابط موقعك من غير أي مسار، زي `https://اسمك.github.io`
- دوس Deploy.
- **اتأكد إنه شغال:** افتح في المتصفح `https://study-tutor.<حسابك>.workers.dev/api/tts/voices`. المفروض تلاقي قايمة أصوات فيها `ar-EG-ShakirNeural`.

**٣) اربط الموقع بالسيرفر:**
- في `config.js` حط `proxyUrl: "https://study-tutor.<حسابك>.workers.dev"`، وارفع الملف على GitHub.
- افتح الموقع ← ⚙️ ← الصوت. المفروض يكتب «شغال دلوقتي: سيرفر الموقع»، والصوت الافتراضي «شاكر — مصري».
- الشات بيفضل على الذكاء المجاني زي ما هو، لأن السيرفر ده متظبط للصوت بس.

## تحديث: شيل اللاج + صوت أسرع + ذكاء أعلى
- **اللاج وقت ما الرد بيتكتب اتشال:** الرد مبقاش بيتعاد رسمه كله كل شوية. الأجزاء اللي خلصت بتفضل ثابتة، والجزء الأخير بس اللي بيتحدّث (`mdLive` في app.js).
  - على موبايل متوسط: التهنيج في رد طويل نزل من ~1100ms لـ ~60ms، وأطول تهنيجة من ~540ms لـ ~100ms.
- **صوت «كريم» على الجهاز بقى أسرع بكتير:**
  - المحرك بيفضل شغال بدل ما يتبني من الأول مع كل جملة (كان بيضيّع ~600ms في كل جملة).
  - الجملة كلها، عربي + English، بتطلع في ملف واحد متصل.
  - الوقفات بين الجمل ~10ms.
  - أول مرة بس الموديل بيتحمّل. التحميل بيبدأ في الخلفية مع أول سؤال لو النت كويس.
  - الأجهزة البطيئة بتاخد النسخة الأخف تلقائيًا.
- **إصلاح وقوع الصوت:** المحرك كان بيقع لو صوت إنجليزي قرا كلام عربي أو العكس. دلوقتي الأصوات بتتحوّل بجدول الموديل نفسه، زي Piper الأصلي.
- **ذكاء أعلى، «تلقائي» هو الافتراضي:**
  - المسائل والحسابات والمقارنات و«ليه» والامتحانات بتروح لأذكى موديل (GPT-OSS 120B بتفكير متوسط).
  - الكلام العادي والشرح بيروح للأسرع، عشان الرد ميتأخرش.
  - الحل بيراجع كل خطوة ورقم قبل الإجابة النهائية.
  - لو اخترت موديل بنفسك من ⚙️، اختيارك هو اللي بيمشي.

## الجديد: الكتابة على الكتب + صوت الـ AI
- **أدوات الكتابة** (شريط تحت شريط الصفحات): 👆 تحديد/تمرير (الوضع العادي واسأل AI) — 🖊️ قلم — 🖍️ هايلايتر — 🔤 نص بالكيبورد — 🧽 ممحاة — ألوان وسُمك — ↩️ تراجع (Ctrl+Z) — 🗑️ مسح كتابة الصفحة.
  - الكتابة بتتحفظ تلقائيًا في المتصفح لكل كتاب وصفحة، وبتفضل مكانها مع التكبير والتصغير.
  - على الموبايل: وانت في وضع القلم الإصبع بيكتب ومش بيعمل تمرير، فاضغط 👆 عشان تتحرك في الصفحات.
  - ⚠️ الكتابة محفوظة في نفس المتصفح والجهاز بس (زي الكتب)، ومسح بيانات المتصفح بيمسحها.
- **الصوت**:
  - 🔊 اسمع: زرار تحت كل رد بيقراه بصوت عالي.
  - 🔇/🔊 (جنب اختيار الكتاب): قراءة تلقائية لكل الردود.
  - 🗣️ محادثة صوتية: اضغط مرة واحدة، اتكلم، والـ AI يرد بصوته وبعدين يسمعك تاني لحد ما تضغط ⏹. الردود بتبقى أقصر في الوضع ده.
  - ⚙️ الإعدادات ← «صوت الـ AI»: اختار الصوت اللي يعجبك وجرّبه. أصوات Chrome وEdge العربي أحسن من غيرهم. الصوت والميكروفون بيستخدموا إمكانيات المتصفح نفسه، من غير مفاتيح إضافية.

## الصوت الطبيعي (Gemini) واختيار الصوت
- الصوت الافتراضي بقى **Gemini TTS** لو فيه مفتاح Gemini (نفس المفتاح المجاني بتاع الموقع). أصوات طبيعية أحسن بكتير من أصوات المتصفح، وبتفهم العربي المصري والإنجليزي في نفس الجملة.
- ⚙️ الإعدادات ← «صوت الـ AI»: قايمة فيها ٣ مجموعات: أصوات مصرية (لو متاحة لمفتاحك)، و٣٠ صوت Gemini، وأصوات المتصفح. اختار وجرّب بزرار 🔊.
- لو بتستخدم Claude كمزود، هيظهر حقل صغير لمفتاح Gemini للصوت بس.
- لو الصوت الطبيعي فشل (حد مجاني خلص مثلًا)، الموقع بيكمّل بصوت المتصفح ويقولك السبب.
- الأصوات اللي اتولّدت بتتخزن مؤقتًا، فإعادة سماع نفس الرد مبتستهلكش من الحد المجاني.

## الصوت المحلي (بلا حد) — الافتراضي الجديد
- لو مفيش مفتاح Gemini، الموقع بيستخدم موديل **MMS عربي** (`Xenova/mms-tts-ara`) شغال جوه المتصفح عن طريق transformers.js: بلا مفاتيح، بلا حد يومي، ومبيبعتش كلامك لأي سيرفر.
- أول مرة بيحمّل حوالي ٤٠ ميجا من الإنترنت (بيظهر النسبة على زرار 🔊)، وبعدها بيتخزن في كاش المتصفح ويشتغل من غير نت.
- الجمل الإنجليزي بتتقرأ بصوت المتصفح لأن الموديل عربي بس.
- لو فشل التحميل بيكمّل بصوت المتصفح ويقولك السبب.
- ⚙️ الإعدادات ← «صوت الـ AI» ← «🧠 صوت محلي». Gemini لسه متاح كاختيار لو عايزه.
- ملحوظة: الموديل بينطق أقرب للفصحى مش لهجة مصرية، وأول رد بياخد ثواني للتجهيز على الموبايل.

## تحسين صوت المتصفح
- الاختيار التلقائي بقى بيفضّل أصوات Natural/Neural (Edge)، بعدين Premium/Enhanced (iPhone وMac)، بعدين Google، مع أفضلية للهجة المصرية.
- قايمة أصوات المتصفح في الإعدادات مترتبة من الأحسن للأسوأ، والأصوات الطبيعية عليها ⭐.
- سرعة وطبقة النطق اتظبطت، والنص بيتنضّف قبل القراءة عشان الكلمات الإنجليزي جوه الجملة العربي تتقرأ أوضح.
- أحسن نتيجة: **Edge على ويندوز** (سلمى وشاكر)، أو **Chrome على أندرويد** مع Google Speech Services.

## تحديث: منع تجمّد الصفحة
- الموديل المحلي بقى شغال في Web Worker منفصل، فالصفحة مبتتجمدش وقت تجهيز الصوت.
- الاختيار التلقائي: لو المتصفح فيه صوت عربي Natural (Edge: سلمى/شاكر) بيستخدمه، وإلا بيستخدم الموديل المحلي.

## أصوات رجالي/حريمي + قراءة متصلة + إنجليزي أوضح
- ⚙️ الإعدادات ← «صوت الـ AI»: فيه «⚡ اختيار سريع» (أحسن صوت رجالي / نسائي متاح)، وأصوات محلية بأسماء (ليلى، كريم، سالم، نور)، وعلامة 👨/👩 على أصوات المتصفح وGemini.
- ملحوظة: الأصوات المحلية كلها من موديل واحد بنغيّر طبقته، فـ«كريم» و«سالم» صوت رجالي بالمحاكاة. أصدق صوت رجالي حقيقي هو **شاكر** في Edge.
- الكلام بيتقسم لأجزاء عربي/إنجليزي، والإنجليزي بيتقرأ بصوت إنجليزي مناسب ونفس النوع (رجالي/نسائي) بدل ما الصوت العربي يقرأه.
- القراءة بقت متصلة: أجزاء المتصفح بتتحط في الطابور مرة واحدة، والمحلي بيجهّز الجزء الجاي وهو بيقرا اللي قبله.
- فيه اختيار «سرعة القراءة» تحت قايمة الصوت..

## واجهة جديدة + أصوات بأسماء حقيقية
- تصميم احترافي جديد: أيقونات SVG بدل الإيموجي، وضع فاتح وداكن، وإعدادات منظمة في كروت (الذكاء الاصطناعي / الصوت).
- الأصوات العربي في Edge بتظهر بأسمائها: «سلمى — مصر» و«شاكر — مصر»، وعليها 👨/👩.
- اتشالت أصوات «كريم/سالم/نور» لأنها كانت محاكاة بتغيير طبقة الصوت وطالعة وحشة. الرجالي الحقيقي: شاكر (Edge) أو أصوات Gemini الرجالي.
- «الشغال دلوقتي» في الإعدادات بيوريك بالظبط أنهي صوت عربي وإنجليزي بيقرا بيهم.
- «الإنجليزي جوه الكلام العربي»: منفصل (أوضح) أو بنفس الصوت (أسلس).

## تحديث: سرعة التجهيز + صوت عربي أحسن
- **الاختيار التلقائي** بقى بيستخدم أي صوت عربي حقيقي في المتصفح (فوري، من غير تجهيز) بدل الموديل المحلي البطيء. الموديل المحلي بيشتغل بس لو جهازك مفيهوش أي صوت عربي.
- **🌐 صوت جوجل** (جديد، في الإعدادات ← «صوت الـ AI»): بيبدأ في أقل من ثانية لأنه ملف صوت جاهز من غير توليد، وبيقرا العربي والإنجليزي بنفس الصوت. محتاج إنترنت، وبيبعت النص لجوجل. لو فشل بيكمّل بصوت المتصفح.
- **الصوت المحلي أسرع**: الموديل بيتسخّن في الخلفية أول ما الموقع يفتح (بعد أول تحميل)، وأول جزء من الرد قصير عشان الصوت يبدأ بسرعة، والأجزاء الجاية بتتجهّز وهو بيقرا.
- **سبب إن الصوت العربي مكانش بيتغير**: أصوات Gemini كانت ظاهرة في القايمة حتى من غير مفتاح، فلو اخترت واحد منها كان بيقرا بصوت المتصفح العادي. دلوقتي بتظهر بس لو حطيت مفتاح Gemini. والموديل المحلي صوت واحد بس، فمفيش فيه اختيارات.
- لو عايز أصوات عربي مختلفة فعلًا: Edge على ويندوز (سلمى وشاكر)، أو مفتاح Gemini.

## تحديث: شرح الدرس + صوت محلي حقيقي (كريم)
- **🎓 اشرح الدرس** (جنب «حل الصفحة»): افتح أي صفحة واضغط الزرار، والـ AI يقرا الصفحة ويشرحها زي مدرس (فكرة الدرس، النقط الأساسية بأمثلة، ملخص، وسؤالين للاختبار)، وبعدين يقراها لك بصوت عالي أوتوماتيك.
- **👨 كريم**: صوت رجالي عربي محلي حقيقي (موديل Piper `ar_JO-kareem-medium`)، أطبع بكتير من MMS. بيشتغل جوه المتصفح من غير مفتاح ولا حد يومي. أول مرة بيحمّل حوالي ٦٠ ميجا، وبعدها بيتخزن ويشتغل بدون نت.
- الاختيار التلقائي: لو المتصفح فيه صوت عربي Natural (Edge: سلمى/شاكر) بيستخدمه، وإلا بيستخدم كريم. لو كريم فشل بيكمّل بـ MMS.
- تقدر تختار «كريم» أو «MMS» بإيدك من ⚙️ ← «صوت الـ AI» ← «🧠 صوت محلي».

## تحديث: شرح الدرس كله (مش صفحة واحدة)
- زرار **🎓 اشرح الدرس** أو كتابة/قول «اشرحلي الدرس» بيبعت **٤ صفحات متتالية** من الصفحة اللي واقف عليها، والـ AI بيشرح الدرس لحد ما يخلص ويقف عند بداية أي درس جديد.
- لو الدرس لسه مكمّل بعد الـ٤ صفحات بيقولك، وبتقول «كمّل» (أو تضغط زرار «كمّل الشرح») فيكمّل من آخر صفحة اتشرحت. الملخص وأسئلة الاختبار بتيجي في آخر الدرس بس.
- تقدر تقول اسم الدرس: «اشرحلي درس الفتوحات الإسلامية». الموقع بيدوّر عليه في نص الكتب ويفتح عليه ويشرحه. (ده بيعتمد على نص الـ OCR، فلو الاسم مش متلاقي افتح أول صفحة في الدرس بإيدك وقول «اشرحلي الدرس».)
- بيشتغل كمان في المحادثة الصوتية 🗣️، وبيتقري بصوت عالي.

## الذكاء المحلي «ذكي» (بلا حد، بلا مفتاح، من غير Gemini)
- بقى هو الاختيار الافتراضي لو جهازك بيدعم WebGPU. موديل لغة مفتوح المصدر (Qwen) بيشتغل **جوه المتصفح** عن طريق WebLLM: مفيش حد يومي، مفيش مفتاح، وكلامك مبيتبعتش لأي سيرفر.
- التحميل مرة واحدة: حوالي ١ جيجا (خفيف) لحد ٣ جيجا (قوي)، وبعدها بيتخزن ويشتغل من غير نت. الحجم بتختاره من ⚙️ ← المزوّد ← «ذكي». الافتراضي بيتحدد حسب ذاكرة جهازك.
- شخصيته: مدرّس مصري ظريف وصبور بيشرح خطوة خطوة وبيشجع الطالب.
- **بيقرا نص الصفحة مش الصورة** (الموديل المحلي مبيشوفش صور): بياخد طبقة النص من الـ PDF، ولو الصفحة صورة بيعمل OCR عربي بمكتبة tesseract.js (بتتحمّل أول مرة من النت). دقة الإجابة بتعتمد على دقة النص المستخرج.
- الردود بتظهر وهي بتتكتب، والدرس بيتشرح على دفعات من صفحتين ويكمّل بـ «كمّل».
- Gemini وClaude لسه متاحين كاختيار من ⚙️ لو عايز ذكاء أقوى وبتشوف الصور.
- المتطلبات: Chrome حديث على أندرويد ١٢+، أو Chrome/Edge على الكمبيوتر، أو iOS 18+.

## تحديث: «ذكي» السحابي (Puter) بدل المحلي التقيل
- الموديل المحلي كان بيهنّج الأجهزة الضعيفة (بياخد ذاكرة كبيرة من الجهاز). فالافتراضي الجديد بقى **✨ «ذكي» عن طريق Puter.js**: مفيش مفتاح ومفيش Gemini، **بيشوف الصور** زي الأول، والشغل كله على سيرفراتهم فجهازك مبيتحملش حاجة.
- بيستخدم موديلات OpenAI/Qwen (مش Google). الافتراضي «سريع وخفيف»، وتقدر تختار «أذكى» من ⚙️ ← المزوّد ← «ذكي».
- أول مرة اضغط ⚙️ ← «تسجيل دخول Puter» (حساب مجاني). بعد كده كل مستخدم بيستخدم رصيد حسابه هو، فمفيش حد يومي عليك أنت كصاحب موقع.
- الذكاء المحلي لسه موجود كاختيار للمتقدمين، بس بقى الحجم الافتراضي فيه «خفيف/صغير جدًا» ومبيتحملش لوحده أول ما الموقع يفتح.
- لو حصل خطأ في اسم موديل (لأن Puter بتغيّر الأسماء)، الموقع بيجرّب موديل بديل تلقائيًا.

## تحديث: إصلاح هنج الجهاز
- اتلغى التسخين التلقائي للموديلات المحلية (الصوت والذكاء) عند فتح الموقع أو اختيار الصوت — كانت بتاخد ذاكرة ومعالج كتير.
- الصوت الافتراضي/التلقائي لما مفيش صوت عربي في المتصفح بقى «🌐 صوت جوجل» (خفيف) بدل الموديل المحلي.
- أي مستخدم كان مختار صوت محلي أو ذكاء محلي بيتحوّل تلقائيًا للخفيف (مرة واحدة). الاختيار اليدوي لسه متاح من الإعدادات.
- موديل MMS بيشتغل بـ thread واحد، والحجم الافتراضي للذكاء المحلي بقى «صغير جدًا.».

## تحديث: إصلاح هنج الجهاز عند تحميل الذكاء المحلي
- الموديل بقى بيشتغل في **Web Worker** منفصل (WebLLM)، فالصفحة والجهاز مبيتجمدوش وقت التحميل والرد.
- اتشالت الأحجام الكبيرة (متوسط/قوي). المتاح: «صغير جدًا» (افتراضي) و«خفيف»، وأي اختيار قديم كبير بيرجع للصغير مرة واحدة.
- فحص كارت الشاشة قبل التحميل: لو ضعيف بيقولك بدل ما الجهاز يهنج.
- زرار التحميل بيسألك تأكيد أولًا، وتحديث النسبة والردود اتخفف، والموديل بيتفرّغ من الذاكرة لما تقفل الصفحة.
- مفيش تحميل تلقائي للموديل عند فتح الموقع.

## تحديث: شيل الذكاء المحلي نهائيًا
- الذكاء المحلي (WebLLM) اتشال من الموقع: مبيتحمّلش ولا بيستخدم كارت الشاشة أو الذاكرة نهائيًا. أي حد كان مختاره بيتحوّل لـ «ذكي» (Puter) تلقائيًا.
- الاختيارات المتاحة: ✨ ذكي (سحابي، الافتراضي)، Gemini، Claude.

## تحديث: «مجاني بدون تسجيل» (الافتراضي الجديد) + إصلاح Puter
- **🆓 مجاني بدون تسجيل ولا مفتاح ولا تحميل**: بيجرّب خدمات سحابية مفتوحة بالترتيب (Kilo ← LLM7 ← OVH). مفيش حاجة بتتحمّل على جهازك. الحد (لو فيه) بيتحسب على IP كل مستخدم. بيقرا **نص** الصفحة (مش الصورة)، فدقته بتعتمد على نص الكتاب في `data/pages.js`.
- ⚠️ الخدمات دي مجانية وممكن تتغيّر أو تقف، والنص اللي بتسأل عنه بيتبعت لسيرفراتهم (متكتبش بيانات شخصية).
- **خطأ Puter «Unsupported Protocol»**: سببه فتح الموقع بالضغط المزدوج (`file://`). Puter مش بيشتغل كده. الحل: استخدم الاختيار المجاني الجديد، أو ارفع الموقع على GitHub Pages / شغّل `python -m http.server`.
- Puter مبقاش بيتحمّل تلقائيًا، وبيتحمّل بس لو اخترته.
- استخراج النص بقى يستخدم نص الكتاب الجاهز قبل الـ OCR (الـ OCR أتقل على الجهاز).

## تحديث: إصلاح «الخدمات المجانية مش متاحة»
- LLM7 بقى بيستخدم الاختيارات التلقائية (`fast` / `default`) بدل اسم موديل ثابت كان اتشال من عندهم.
- OVH حده ٢ طلب/دقيقة لكل موديل، فالموقع بيلف على ٧ موديلات مختلفة، والخدمة اللي بتوصل للحد بتتاجل دقيقة.
- Kilo اتحطت آخر واحدة: «Failed to fetch» معناها إن متصفحك مبيسمحش بالطلب (CORS) وده مش بإيدي.

## تحديث: تحديد سؤال بيحل السؤال بس + اختيار الموديل في المجاني
- **تحديد سؤال/سطر** مع المزوّدات النصية (المجاني والمحلي) كان بيبعت نص الصفحة كلها. دلوقتي بيبعت **نص الجزء المحدد بس**: من طبقة نص الـ PDF حسب المكان، ولو الصفحة صورة بيعمل OCR على الجزء المقصوص بس.
- في وضع «🆓 المجاني» ظهرت قايمة اختيار الموديل (⚡ سريع / 🧠 أذكى GPT-OSS 120B / Qwen للعربي) من غير أي تسجيل. موديلات Puter نفسها (GPT nano / GPT-5.5) محتاجة حساب Puter ومفيش طريقة تشتغل من غيره.

## تحديث: تحديد سؤال = حل السؤال ده بس
- أوامر جديدة للـ AI لما تحدد جزء: يحل **سؤالًا واحدًا فقط** (أول سؤال كامل) ويتجاهل بقايا الأسئلة التانية المقطوعة، ويجاوب بشكل مختصر («الإجابة: (ب) ...» + شرح قصير).
- استخراج النص بالمكان اتصلّح (تحويل إحداثيات صح)، ولو طبقة نص الـ PDF مش دقيقة (سطور/فقرات كبيرة) بيعمل OCR للصورة المقصوصة بدل ما يبعت الصفحة كلها.

## تحديث: الموقع بيسمع كلامك (كتابة أو صوت)
- **عدد الأسئلة**: «حل سؤالين» / «حل ٣ أسئلة» / «حل سؤال ٥» / «حل الأسئلة كلها» بينفّذ بالظبط. ولو قلت «حل سؤال» من غير عدد بيحل واحد بس.
- **مع التحديد**: حدد جزء على الصفحة وبعدين اكتب أو قول طلبك («حل السؤالين دول»، «اشرحلي ده»، «ترجم») وبيشتغل على الجزء المحدد بس.
- **اقرالي**: «اقرالي كلمات» = كلمة واحدة، «اقرالي كلمتين / ٣ كلمات» = العدد ده، «اقراها كلها» = الكل. بيشتغل كمان مع «جملة/جمل» و«سطر» و«سؤال» و«الصفحة». لو فيه تحديد بيقرا منه، وإلا من الصفحة الحالية. وبيتقري بصوت عالي.
- **اشرح درس كذا** شغال زي ما هو (وبالاسم كمان).

## تحديث: التحديد بالأصفر (السطر) بقى بيحل السؤال الكامل
- لما تدوس على سطر من سؤال (الشريط الأصفر) مع المزوّدات النصية، الموقع بقى بياخد **السؤال كله** (السطور اللي فوق وتحت السطر ده بما فيها الاختيارات) ويحدد السطر اللي أشّرت عليه، وبيحل السؤال الكامل ده بس. قبل كده كان بيبعت السطر لوحده فبيقول «مش سؤال كامل».
- لو الصفحة صورة بيعمل OCR على شريط عريض حوالين السطر بس (خفيف).

## صوت Gemini المجاني (عن طريق Puter)
- ⚙️ الإعدادات ← «صوت الـ AI» ← مجموعة «✨ صوت Gemini مجاني». اختار أي صوت، هيفتح تسجيل دخول Puter (حساب مجاني، مرة واحدة)، وبعدها بيبقى هو الصوت الافتراضي.
- مفيش مفتاح. لو التسجيل ماتمش أو النت وقع، الموقع بيكمّل بصوت المتصفح ويقولك السبب.
- بيشتغل على GitHub Pages أو سيرفر محلي، مش بالضغط المزدوج (file://).

## ترقية كبيرة: مدرّس ذكي لأي PDF (RAG + لهجات + امتحانات + صوت طبيعي)
الموقع زي ما هو (نفس التصميم ونفس الأدوات)، واللي اتغير هو «مخ» الـ AI:

### فهم أي ملف (مش كتاب معين ولا منهج معين)
- **فهرس دروس تلقائي**: بيطلّع الوحدات/الفصول/الدروس (عربي وإنجليزي: «الدرس الأول»، «Unit 2»، «Lesson 3»…) من العناوين وحجم الخط، ويحدد كل درس من صفحة كام لكام، وبيتجاهل صفحة الفهرس والعناوين المتكررة أعلى كل صفحة.
- **أرقام الصفحات المطبوعة**: لو الكتاب مكتوب فيه «ص ٢٧» وهي صفحة ٣١ في الملف، الموقع بيفهم ده. «حل السؤال اللي في صفحة 27» بيروح للصفحة الصح، والمصادر بتتكتب بترقيم الكتاب وبتفتح الصفحة الصح في العارض.
- **تقسيم لمقاطع + بحث هجين**: كل صفحة بتتقسم لفقرات مربوطة بعنوان الدرس ورقم الصفحة. البحث بالكلمات (مع تصحيح أخطاء الـ OCR) + **بحث بالمعنى (embeddings)** لو متاح، والنتيجتين بيتدمجوا. للـ AI بيتبعت أقرب المقاطع بس، مش الكتاب كله.
- **ضغط السياق**: «لخص الفصل» في فصل كبير = أهم الجمل من كل صفحة (التعريفات، العناوين، القوانين، الأرقام) على قد حجم الموديل.
- الـ OCR للصفحات الصور بقى بيتحفظ في الفهرس (كان بيضيع)، وبيشتغل لأي كتاب محفوظ مش المفتوح بس. لغة الـ OCR بتتحدد تلقائيًا من نص الكتاب.

### بيفهم الطلب من غير ما تختار «وضع»
أمثلة بتشتغل كتابة أو صوت: «اشرحلي أول درس»، «لخص الفصل ده»، «حل السؤال اللي في صفحة 27»، «مش فاهم»، «اعمللي امتحان على الفصل الأول»، «اعمللي 10 MCQ»، «اديني أسئلة أراجع بيها»، «اشرحها بطريقة بسيطة»، «ايه أهم الحاجات اللي لازم أحفظها؟»، «قارن بين …»، «اعمللي ملخص للمذاكرة»، «اختبرني سؤال سؤال»، «صححلي الإجابة»، «اعمللي فلاش كارد»، «فين اتكلم عن …؟»، «ايه الدروس اللي في الكتاب؟»، «الدرس اللي بعده»، «طب اللي بعدها؟».
- **المصادر**: كل معلومة من ملفك جنبها زرار صغير «ص 12» يفتح الصفحة، وتحت الرد قايمة المصادر. أرقام الصفحات بتيجي من الكود نفسه مش من الـ AI، فمينفعش يألّف رقم صفحة (أي مصدر مش موجود بيتشال).
- بيفرّق بين «في ملفك…» و«💡 من عندي:»، ولو المعلومة مش في الملف بيقول كده وبعدين يجاوب من معلوماته. ولو السؤال ملوش علاقة بالملف بيجاوب عادي.
- **«مش فاهم»** = شرح بطريقة مختلفة تمامًا (تشبيه تاني، مثال أبسط، خطوات أصغر) مش تكرار.
- **الامتحانات**: أسئلة من ملفك بس (اختيار من متعدد / صح وغلط / أسئلة قصيرة) بتضغط على الإجابة وتعرف صح ولا غلط وليه ومن أنهي صفحة. «اختبرني سؤال سؤال» = امتحان تفاعلي بالكتابة أو بالصوت («ب» / «مش عارف» / «كفاية») وفي الآخر النتيجة والأسئلة اللي محتاج تراجعها. وفيه **فلاش كاردز** بتتقلب بالضغط.
- **الذاكرة**: بيفهم «دي/ده/اللي بعدها/اديني مثال عليها» من آخر كلام، من غير ما يبعت المحادثة كلها: آخر ٢–٣ ردود + ملخص صغير للمواضيع القديمة + «آخر حاجة كنا بنذاكرها».
- **اللهجة تلقائي**: مصري ← يرد مصري، سعودي/خليجي ← يرد خليجي، فصحى ← فصحى، English ← English، والخلط عادي. نفس اللهجة بتروح للصوت ولميكروفون المحادثة (زرار «ع / خ / EN»).
- الردود بتظهر وهي بتتكتب (streaming) مع كل المزوّدات، والجداول بتتعرض.

### الصوت
- تحت كل رد: **اسمع / إيقاف مؤقت / كمّل — إيقاف — إعادة — السرعة (1× …)**.
- في المحادثة الصوتية والقراءة التلقائية: **الصوت بيبدأ من أول جملة** وهو لسه بيكتب الباقي.
- مع سيرفر الموقع: أصوات بشرية حقيقية — **Azure** (سلمى/شاكر مصري، زارية/حامد سعودي، Ava/Andrew إنجليزي) أو ElevenLabs أو OpenAI أو Gemini، واللهجة بتتختار تلقائي من كلام الطالب. من غير السيرفر كل الأصوات القديمة شغالة زي ما هي (وبقت بتختار اللهجة كمان)، وصوت المتصفح بقى احتياطي بس.
- لو المتصفح مفيهوش تعرّف على الكلام (زي Firefox) والسيرفر فيه STT، الميكروفون والمحادثة الصوتية بيشتغلوا عن طريق السيرفر (بيقف لوحده بعد ثانية سكوت).

### الأمان والخصوصية
- **كتب كل مستخدم في متصفحه هو بس** (IndexedDB): الملف والفهرس والـ embeddings. مفيش سيرفر بيخزن كتب، فمستخدم مستحيل يوصل لكتب مستخدم تاني. البحث بيدور بس في الكتب المحفوظة عند المستخدم الحالي. مسح الكتاب بيمسح الفهرس والـ embeddings بتوعه.
- **ولا مفتاح في كود الموقع**. مع سيرفر الموقع المفاتيح environment variables على السيرفر بس. (اختيار «مفتاح Claude/Gemini» القديم لسه موجود: المستخدم بيحط مفتاحه هو ويتحفظ في متصفحه هو بس.)
- السيرفر: بيقبل طلبات موقعك بس (ALLOWED_ORIGINS)، حد لعدد الطلبات لكل IP، حد لحجم الطلب، ومبيخزنش أي حاجة.

### تشغيل سيرفر الموقع (اختياري بس بيفرق جدًا)
شوف `server/README.md`. باختصار:
1. Cloudflare (مجاني): `cd server && npx wrangler deploy` وحط المفاتيح بـ `npx wrangler secret put ANTHROPIC_API_KEY` (و`AZURE_SPEECH_KEY`…)، وعدّل `ALLOWED_ORIGINS` في `wrangler.toml` لرابط موقعك.
2. في `config.js`: `proxyUrl: "https://study-tutor.<اسمك>.workers.dev"`.
3. أو على أي جهاز فيه Node 18+: `node server/node.mjs` (بيعرض الموقع كمان) و`proxyUrl: "/"`.

### حدود لازم تعرفها

- فهرس الدروس بيتعمل من العناوين آليًا؛ لو الكتاب مفيهوش عناوين واضحة افتح أول صفحة في الدرس وقول «اشرحلي الدرس ده».
- الجداول في الـ PDF بتتقري كنص (مش كجدول)، والـ OCR ممكن يغلط في الصفحات الصور الضعيفة.

## ترقية: مدرّس حقيقي + واجهة حديثة + صوت أشطر
### المدرّس
- **بيختار شكل الرد لوحده**: سؤال بسيط = إجابة مباشرة، شرح = «💡 الفكرة ببساطة ← الشرح ← مثال ← الخلاصة»، مفهوم صعب = من الأساس خطوة خطوة وسؤال يتأكد بيه، اختيار من متعدد = الإجابة وليه صح وليه الباقي غلط وقاعدة تفتكرها، درس كامل = نظرة عامة ← المفاهيم ← افتكر ← أخطاء شائعة ← الخلاصة.
- **أوضاع تلقائية حسب كلامك**: شرح، مراجعة («راجع معايا قبل الامتحان» / «اعمللي مراجعة على الوحدة»)، امتحان («اديني أسئلة صعبة» — الإجابات مستخبية لحد ما تجاوب)، سؤال سؤال، فلاش كاردز، واجب («حل السؤال ده» = فكرة الحل ← الخطوات ← الإجابة النهائية، و«الإجابة بس» = مباشرة)، «ليه الإجابة دي صح؟»، «اشرحلي كأني أول مرة أدرس الموضوع».
- **«مش فاهم» بتتدرج**: أول مرة شرح بطريقة تانية، تاني مرة أبسط بكتير مع تشبيه من الحياة، تالت مرة خطوة بخطوة مرقّمة ويسألك «فهمت لحد خطوة كام؟».
- **بيفهم ترتيب الكتاب**: «اشرحلي الدرس اللي بعد الوحدة التانية»، «الفصل اللي قبل الدرس التالت». و«الجزء ده / الكلام ده» = الصفحة المفتوحة (أو الجزء اللي حددته).
- البحث بيجيب كمان المقطع اللي بعد أقوى نتيجة في نفس الدرس لأنه غالبًا بيكمّل الفكرة.

### الواجهة
- ردود نضيفة من غير فقاعات تقيلة، وأقسام ملوّنة للفكرة/المثال/افتكر/الأخطاء الشائعة/الخلاصة، و«الإجابات» مقفولة لحد ما تفتحها. جداول وكود ومعادلات (KaTeX بيتحمّل بس لو فيه معادلة).
- تحت كل رد: **نسخ** (بأرقام الصفحات من غير رموز)، **إجابة تانية**، والصوت (اسمع / إيقاف مؤقت / إيقاف / إعادة / السرعة). وعلى سؤالك زرار **تعديل**: بتعدّل وتبعت، والمحادثة بتكمل من عنده.
- **مربع كتابة دائري**: Enter للإرسال وShift+Enter لسطر جديد، وبيكبر مع الكلام، وزرار الإرسال بيبقى **⏹ وقّف** وقت الرد (بيوقف أي مزوّد، والجزء اللي اتكتب بيفضل).
- شاشة ترحيب باقتراحات، وسكرول ذكي (مبيشدّكش لو بتقرا فوق) مع زرار «انزل لآخر الكلام»، وأنيميشن خفيف بيتقفل لو جهازك مفعّل «تقليل الحركة»، والوضع الليلي متظبط لكل حاجة جديدة.

### الصوت
- شريط المحادثة الصوتية فيه دايرة بحالة واضحة: **سامعك** (حلقة بتنبض) / **بفكّر** / **بتكلم** (موجة صوت) — CSS بس فمفيش حمل على الموبايل. دوس الدايرة وهو بيتكلم عشان تقاطعه وتسأل على طول.
- الكلام المسموع نسخة طبيعية من الرد: العناوين بتتقال جمل، الجداول صف صف، المعادلات بتتقري بالكلام، ومفيش «نجمة» ولا «شباك» ولا أرقام مصادر، والإجابات المستخبية مبتتقريش.
- شخصية الصوت: هادي وواضح وودود وصبور، واثق من غير مبالغة في الحماس.
- رسايل واضحة لو الميكروفون مقفول أو مش موجود أو المتصفح مبيدعمش التعرّف على الكلام.

## ترقية: الكتاب المحدد هو المصدر الوحيد + أوامر الدروس بالظبط + صوت Gemini
### قفل المصدر
- **الكتاب المحدد** = اللي ظاهر في القايمة جوه مربع الكتابة، وبيتظبط لوحده على الكتاب اللي فتحته. البحث بيحصل فيه هو بس، ومفيش أي تنقّل صامت لكتاب تاني (إلا لو كتبت اسم الكتاب التاني صراحة). لو فيه كذا كتاب ومفيش كتاب محدد، بيسألك تختار.
- لو المعلومة مش في الكتاب المحدد الرد بيبقى: **«مش لاقي المعلومة دي في الكتاب المحدد.»** — من غير أي إجابة من برّه. ولو عايز معلومات إضافية قول «اشرحها من بره الكتاب» أو «اديني معلومات إضافية من خارج المنهج»، ووقتها الإضافة بتتكتب تحت «🌐 من خارج الكتاب».
- القفل ده على مستويين: لو البحث مالقاش أي مقطع، الرد بييجي فورًا من غير ما نسأل الـ AI خالص. ولو لقى مقاطع، الـ AI بيتعلّم إنه يجاوب منها بس ويقول نفس الجملة لو الإجابة مش فيها. التبسيط والتشبيهات مسموحة من غير أي معلومة علمية جديدة.
- نفس القفل على «حل الصفحة» والتحديد وشرح الدرس والامتحانات (الأسئلة من الكتاب بس).

### أوامر الدروس
- «اشرحلي الدرس 3» / «اشرح الدرس الثالث» / «الدرس ٣» / «Lesson 3» / «Explain Lesson 3» / «لخص الدرس 4» / «Summarize Lesson 4» / «اديني أسئلة على الدرس 2» / «Quiz me on Lesson 5» / «اختبرني في الدرس 5»: كلهم بيروحوا لعنوان «الدرس 3» الحقيقي في فهرس الكتاب المحدد (مش أي رقم 3 في النص، ومش «الفصل 3» بداله).
- «أول درس / تاني درس» = بالترتيب في الكتاب. «الدرس الأول» = الدرس اللي رقمه 1 — ولو الكتاب فيه أكتر من «الدرس 1» (في كل وحدة مثلًا) بيسألك «تقصد أنهي واحد؟» بأزرار، أو قول «الدرس 1 من الوحدة 2».
- لو الدرس مش موجود: «مش لاقي «الدرس 9» في الكتاب المحدد» ومعاها قايمة الدروس الموجودة فعلًا.
- فوق الرد شارة المصدر: **📖 الكتاب · 📚 الدرس · 📄 الصفحات** (بتفتح الصفحة لما تدوس عليها).
- **حالة الدرس**: الشرح بيمشي بالترتيب لحد آخر صفحة في الدرس بالظبط. «كمّل» بتكمّل من نفس المكان في نفس الدرس (مش من الأول)، ولما الدرس يخلص بيقولك وبيعرض الدرس اللي بعده. «اشرح الدرس اللي بعده» = الدرس اللي بعده في فهرس الكتاب.

### الصوت
- ترتيب الصوت على السيرفر بقى: **Gemini TTS** ← ElevenLabs ← Azure ← OpenAI ← صوت المتصفح (آخر احتياطي). لو Gemini فشل (حد الاستخدام مثلًا) السيرفر بيجرّب اللي بعده قبل ما المتصفح يتكلم.
- Gemini بياخد «ملاحظات مخرج» عشان يتكلم كمدرّس خصوصي مصري هادي وواضح بوقفات طبيعية، وبينطق المصطلحات الإنجليزي صح. الصوت الافتراضي Sulafat (دافئ) أو Achird (رجالي ودود)، وباقي أصوات Gemini في ⚙️. والمفاتيح على السيرفر بس (`GEMINI_API_KEY`).
- لما سيرفر الموقع يبقى فيه صوت، بيبقى هو الافتراضي بدل صوت المتصفح.
- الصوت بيتقطع عند نهاية الجمل (مش في نص الكلام)، والعناوين بتتقال «الفكرة ببساطة: …»، ومفيش رموز ولا أرقام مصادر ولا إيموجي ولا HTML في الكلام.

## تحديث: مصري + English زي Gemini، شات مفتوح، و«الدرس الأول» على طول
- **الكلام**: الرد بالمصري الطبيعي زي Gemini، والمصطلحات العلمية بالإنجليزي جنب العربي («الخلية (cell)»)، والجمل الإنجليزي اللي في الكتاب بتفضل إنجليزي وتتشرح بالمصري. لو كتبت English بيرد English.
- **الشات مفتوح (الافتراضي)**: الكتاب المحدد هو المرجع الأول ومعاه أرقام الصفحات، ولو سألت عن حاجة مش في الكتاب أو أي سؤال عادي بيجاوبك برضه ويقولك إنها «🌐 من خارج الكتاب». لو عايز الكتاب بس: ⚙️ ← «مصدر الإجابات» ← 🔒 الكتاب المحدد بس.
- **«اشرحلي الدرس الأول»** والكتاب محدد تحت: بيجيب أول درس ويشرحه على طول بطريقة المدرسين (نظرة عامة ← المفاهيم ← افتكر ← أخطاء شائعة ← الخلاصة ← اختبر نفسك). لو الكتاب فيه أكتر من «درس 1» (في كل وحدة) بياخد الأول (أو اللي في الوحدة المفتوحة) ويحط تحت الشرح زرار للتاني. ولو الكتاب متقسم فصول مش دروس بيشرح الفصل الأول.
- **صوت Gemini**: الصوت الافتراضي بقى Gemini نفسه بالترتيب ده: سيرفر الموقع ← **مفتاح Gemini المجاني بتاعك** (⚙️ ← الصوت ← خانة المفتاح — بتظهر مع أي مزوّد) ← Gemini المجاني عن طريق Puter ← صوت المتصفح آخر حاجة. صوت واحد بيتكلم مصري ويقول الكلام الإنجليزي بنطق إنجليزي صح من غير ما يغيّر الصوت، بملاحظات «مدرّس مصري هادي وواضح». الافتراضي Achird (رجالي)، وفيه Sulafat وأصوات تانية في ⚙️.

## إصلاح: الصوت الحلو كان بيتغيّر لصوت المتصفح
- السبب: مفتاح Gemini المجاني ليه حد صغير للصوت (كام طلب في الدقيقة وعدد قليل في اليوم)، ولما الحد يخلص الموقع كان بيرجع لصوت المتصفح على طول.
- دلوقتي كل رد بياخد **طلبين بس** من Gemini (أول جملة عشان يبدأ بسرعة + الباقي مرة واحدة) بدل طلبات كتير، فالحد بيكفّي أكتر بكتير.
- لما الحد يخلص الموقع **بيفتكر وقت الانتظار** اللي Gemini قاله ومش بيفضل يجرّب ويفشل، وبعده بيرجع لصوت Gemini لوحده.
- ولحد ما يرجع: **نفس الصوت** (Achird أو Sulafat) بيكمّل عن طريق Puter (حساب مجاني مرة واحدة — بيظهر زرار «🔓 خلّي نفس الصوت يكمّل»)، أو سيرفر الموقع لو موجود، وآخر حاجة أطبع صوت في المتصفح **بنفس النوع** (رجالي لو اخترت رجالي).
- أضمن حل من غير أي حدود: سيرفر الموقع بمفتاح Gemini مدفوع (`GEMINI_API_KEY` على السيرفر).

## صوت واحد بس: Achird من Gemini
- اتشالت كل الأصوات التانية من الإعدادات (أصوات المتصفح، جوجل، الأصوات المحلية، وقايمة أصوات Gemini). فاضل صوت واحد: **👨 Achird — صوت Gemini** (مصري + English بنفس الصوت) وزرار **▶ جرّب**.
- بيشتغل بأول طريقة متاحة: سيرفر الموقع ← مفتاح Gemini المجاني (الخانة في ⚙️) ← Gemini المجاني عن طريق Puter (أول ما تدوس «جرّب» بيطلب تسجيل مرة واحدة). صوت المتصفح بيشتغل بس مؤقتًا لو ولا واحدة من دول متاحة، وبيظهر زرار «🔓 شغّل صوت Gemini».

## صوت Gemini Live (الأقرب لصوت تطبيق Gemini)
- تطبيق Gemini بيتكلم بموديل «native audio» (Gemini Live) مش بموديل قراءة النصوص العادي، وده سبب إن صوته أطبع. الموقع دلوقتي بيستخدم **نفس النوع ده** عن طريق Live API بمفتاح Gemini بتاعك، بصوت Achird.
- الصوت بيشتغل أول ما يوصل (streaming)، والإيقاف المؤقت/الإيقاف/السرعة شغالين عليه.
- الموديل بيتختار تلقائيًا من الموديلات المتاحة لمفتاحك (اللي بتدعم Live)، وبيتقاله يقرا الرد زي ما هو بالظبط بالمصري والـ English بنطقه الصح.
- لو Live مش متاح لمفتاحك أو الحد خلص: بيكمّل بصوت Gemini العادي بنفس الصوت (Achird)، وبعده Puter، وآخر حاجة صوت المتصفح.
- من غير مفتاح Gemini مفيش Live (Puter مبيدعموش)، فحط المفتاح في ⚙️ ← الصوت.

## صوت Gemini Live بيكمّل الكلام للآخر + شرح زي مدرسين يوتيوب
- الصوت بيتبعت لـ Gemini Live جملة جملة (أدوار قصيرة) بدل دفعة واحدة، وبعد كل دور بنقارن اللي اتقال فعلًا (outputAudioTranscription) بالمكتوب.
- لو Live نسي جزء بيتبعتله تاني مرة واحدة؛ ولو لسه ناقص (أو اتأخر ٩ ثواني) الباقي بالظبط بيكمّل بصوت Gemini العادي بنفس الصوت Achird — من غير ما يعيد اللي اتقال.
- أسلوب الشرح بقى زي أشطر مدرسين يوتيوب المصريين: هوك في الأول، تشبيه من الحياة اليومية، شرح خطوة خطوة، جملة تثبيت، تنبيه على اللي بيجي في الامتحان، «تكة» للحفظ، وفي الآخر خلاصة وسؤال.

## الصوت المجاني بلا حدود (الافتراضي)
- **على Microsoft Edge:** بيستخدم صوت «شاكر» المصري (Online Natural) المتاح في المتصفح. ده مجاني ومن غير حدود، والكلمات الإنجليزي بتتقري بصوت «Andrew».
- **على أي متصفح تاني:** بيستخدم «كريم» (Piper `ar_JO-kareem-medium`). ده موديل مفتوح المصدر بيشتغل جوه جهاز الطالب نفسه، من غير مفتاح ولا سيرفر ولا حدود. أول مرة بس بيحمّل حوالي 60 ميجا، وبتفضل محفوظة. الإنجليزي بيتقري بـ«Ryan»، أو بصوت إنجليزي طبيعي من المتصفح لو موجود.
- **لو «كريم» مشتغلش على الجهاز:** بيكمّل بصوت رجالي من المتصفح، مع رسالة بتنصح بـ Edge.
- **صوت Gemini الحقيقي:** بقى اختيار في ⚙️ ← «نوع الصوت»، ومحتاج مفتاح وليه حد يومي.

## شخصية المدرّس (system prompt)
- النص في `server/persona.js` (المصدر الوحيد). السيرفر بيضيفه أول كل رد على `/v1/chat`، فالطالب مبيقدرش يغيّره من المتصفح.
- بعد أي تعديل فيه شغّل `npm run bundle` (بيولّد `persona.js` للمتصفح و`worker-bundle.js`).
- ممكن تغيّره من غير كود: متغيّر `TEACHER_PERSONA` على الـ Worker يستبدله، والقيمة `off` تقفله.
- المزوّدات المجانية/Puter بتاخد نفس الشخصية من المتصفح. الذكاء المحلي الصغير بياخد نسخة مختصرة (سياقه صغير).

## نسخة بكتب جاهزة
- في `config.js` فيه `seedBooks: [{ file, url }]`. كل كتاب فيها بيتحمّل من `books/` أول مرة الموقع يتفتح، ويتحفظ في متصفح المستخدم زي أي كتاب.
- لو المستخدم مسح كتاب مش بيرجع لوحده. لو التحميل فشل (نت ضعيف) بيحاول تاني المرة الجاية.
- ملفات الـ PDF نفسها لازم تتحط في فولدر `books/` بنفس الأسماء. استضافة GitHub Pages بتقبل ملفات لحد 100 ميجا. Cloudflare Pages بيقبل 25 ميجا بس للملف الواحد، فمش هينفع لكتب أكبر منه.
- الكتب هتبقى متاحة لأي حد معاه رابط الموقع، فاستخدمه للشخص اللي المفروض يشوفها بس.
